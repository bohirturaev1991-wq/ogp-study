# OGP — Davlat va huquq asoslari

Веб-приложение (PWA) для изучения Основ государства и права Республики Узбекистан:
для абитуриентов и для учителей (категория, миллий сертификат). Работает в браузере
на телефоне и ПК, «устанавливается» как приложение и работает офлайн.

## Что умеет

- **Библиотека**: учебники по главам, НПА по главам и статьям, uz (латиница) / ru.
- **Читалка**: оглавление, отметка «прочитано», закладки ☆, заметки ✎, «в карточки» ＋, размер шрифта.
- **Поиск** по всем материалам сразу: опечатки, окончания, `o'z` = `oʻz`, переход по «12-modda» / «статья 12».
- **Тесты**: тренировка (ответ сразу + пояснение + ссылка на статью) и экзамен на время,
  «Мои ошибки», «Новые», разбор ошибок, история.
  Кроме ручных вопросов — **авто-вопросы** по любому НПА («в какой статье закреплено…», пропущенные сроки/цифры).
- **Карточки** с интервальным повторением (SM-2): тестовые вопросы, определения из учебников, закладки, свои карточки.
- **План**: дата экзамена → сколько глав в день, задачи на сегодня, слабые места (< 70%), активность, серия дней.
- Прогресс хранится на устройстве; в настройках — выгрузка/загрузка файла прогресса.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist/ — можно выложить на любой статический хостинг
```

## Добавление материалов

### НПА (с lex.uz)

Сейчас загружены все 35 актов из программы по «Юриспруденции» (Гражданский кодекс — двумя частями, итого 36 документов).

1. Добавьте акт в [content/npa.json](content/npa.json): `lex.uz` = ID узбекской (`lex.uz/docs/ID`) и русской (`lex.uz/ru/docs/ID`) версий.
   Для «Положения», утверждённого постановлением, добавьте `"appendix": N` — будет взято только N-е приложение.
2. `npm run import:lex` — скачает и разберёт на главы/статьи. Узбекский текст берётся из официальной латиницы lex.uz
   (`lex.uz/docs/-ID`); если её нет — из кириллицы с автоматической транслитерацией.
   `npm run import:lex -- --force` — перекачать все (после изменений в законах), `npm run import:lex -- labor-code` — один акт.
3. `npm run check:npa` — сводка: статьи, главы, расхождения uz/ru (`npm run check:npa -- labor-code` — подробно).
4. `npm run content`.

### Учебники

Загружены «Основы государства и права» за 8–11 классы на русском и узбекском (узбекские версии — с oliygoh.uz, те же издания). Формат и конвертер из PDF —
[content/books/README.md](content/books/README.md). Markdown-файлы `content/books/<id>.uz.md` / `.ru.md`
+ запись в [content/books.json](content/books.json), затем `npm run content`.

### Вопросы

`content/questions/*.json` — образец: [content/questions/constitution.json](content/questions/constitution.json).
`answer` — индекс правильного варианта (варианты перемешиваются при показе), `art` — номер статьи для ссылки «Источник».

## Структура

```
content/            исходники: списки НПА и книг, тексты книг, вопросы, raw-импорт lex.uz
scripts/            import-lex.mjs (импорт), build-content.mjs (сборка в public/content)
src/                React-приложение (pages/ — экраны, units.ts — деление на главы, autoq.ts — авто-вопросы)
```
