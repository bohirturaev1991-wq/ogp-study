# Учебники

Каждый учебник — отдельный markdown-файл на каждый язык:

    content/books/<id>.uz.md
    content/books/<id>.ru.md

и запись в `content/books.json`. Если файла на одном из языков нет, приложение показывает книгу на имеющемся (с пометкой языка).

Сейчас загружены учебники «Основы государства и права» / «Davlat va huquq asoslari» за 8 (2024), 9 (2024), 10 (2023) и 11 (2025) классы — на русском и узбекском. Оглавления: `src/<id>.<lang>.config.json` (`"lang": "uz"` — узбекские уроки «N-dars», рубрики, апострофы oʻ/gʻ).

## Разметка файла

| Строка                   | Что это                                                     |
|--------------------------|-------------------------------------------------------------|
| `# Название` (первая)    | название книги (не показывается в тексте)                   |
| `# Глава / Раздел`       | глава или раздел учебника — объединяет уроки                |
| `## Урок`                | урок — единица чтения и прогресса                           |
| `### Подзаголовок`       | подзаголовок или рубрика («Запомните!», «Закон определяет!») |
| `> Термин – определение` | определение; автоматически становится карточкой              |
| `**текст**`              | жирный шрифт (как в оригинале)                              |
| `![](img/<id>.<lang>/p007-1.webp "712x521")` | рисунок, схема или таблица со страницы учебника (файлы в `content/books/img/`) |
| пустая строка            | разделяет абзацы                                            |

После изменения: `npm run content` (или `npm run build`).

## Как получить markdown из PDF

Конвертер: `scripts/pdf-book.mjs`. Оглавление книги (разделы и уроки) задаётся вручную в `content/books/src/<id>.config.json` —
по нему конвертер находит уроки в тексте.

PDF с текстовым слоем:

    node scripts/pdf-book.mjs extract "Учебник.pdf" tmp/book.json
    node scripts/pdf-book.mjs convert tmp/book.json content/books/src/ogp-9.ru.config.json content/books/ogp-9.ru.md

Скан без текстового слоя (как «Право 11 класс (2025)»): страницы рендерятся в PNG и распознаются встроенным
OCR Windows (русский; для узбекской латиницы — en-US), результат в формате `[{page, lines:[{t,x,y,r,h}]}]` подаётся в `convert` так же.
В распознанном тексте возможны отдельные опечатки.

Конвертер сохраняет жирный шрифт (по именам шрифтов PDF) и вырезает со страниц рисунки, схемы и таблицы:
страница отрисовывается, основной текст закрывается, оставшиеся области сохраняются картинками (`"pdf"` в config;
повторяющиеся значки и оформление отбрасываются). Затем он отбрасывает подписи к схемам и короткие обрывки (их список — в `<out.md>.dropped.txt`), снимает переносы,
склеивает строки в абзацы и отмечает определения «Термин – это …» и словарь в конце книги.
